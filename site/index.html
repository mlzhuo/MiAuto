What this project actually does

MiAuto is a car-side receiver for ICCOA CarLink — the one protocol behind Xiaomi CarWith, OPPO Car+ and vivo Jovi InCar. It is built on an existing Android Auto head-unit project, with the phone-side protocol swapped for that one — so the parts that were already solid came along, and the new part is the one that needed real testing.

CarWith / Car+ / Jovi InCar

Phone mirroring, received on the car

The app advertises itself as a car that any ICCOA CarLink phone can cast to. Your phone keeps its own maps, music and phone apps; nothing is installed on the phone and nothing needs to be configured on the car beyond the APK itself.

  • The car broadcasts, the phone finds it in the nearby-device list.
  • A 6-digit code is shown on the car and confirmed on the phone.
  • No accounts, no dongle, no cable required.
Pairing

A pairing prompt that comes back

The failure mode that matters is a prompt the user dismissed on the phone: the car is still broadcasting, but the phone will not show the dialog again on its own. MiAuto re-advertises every 30 seconds while it is not connected, which makes the prompt reappear without restarting anything.

  • Re-advertising restarts the broadcast instead of repeating it, because repeating an unchanged broadcast is ignored.
  • An active session is never interrupted by the watchdog.
  • A manual refresh button is available on the home screen for an immediate retry.
Cluster & HUD

Instrument cluster and HUD paths

The base project targets the instrument cluster area that BYD already exposes to third-party apps, and the windshield navigation outputs. Both paths are kept in MiAuto for cars that have them.

  • Cluster projection is opt-in per car and off by default.
  • Where the cluster is not shared with apps, the setting reports the feature as unavailable rather than failing.
  • These paths are carried over and are not yet verified with MiAuto's protocol stack — see the status table.

Made for the car

Install on your car

  1. Download the APK and install it on the head unit through whichever installation route your car permits. Allow installation from unknown sources if it asks.
  2. Open MiAuto once. The home screen shows the car name and a 6-digit pairing code.
  3. On your phone, open CarWith, Car+ 车联 or Jovi InCar (or the equivalent screen-mirroring entry in Settings) and pick this car from the nearby-device list.
  4. Accept the pairing prompt on the phone. The phone screen appears on the car. Do this while parked.

If the phone cannot find the car, keep the phone's Bluetooth and Wi-Fi on, keep both screens awake, and try again. The car re-advertises itself every 30 seconds while it is unconnected, so a pairing prompt that was dismissed on the phone will come back on its own.

What's new

  • 0.1.10 — the fork's first published release, tuned for the BYD 宋 Pro DM-i 2022 head unit. The car starts the app by itself after a reboot, the phone needs no unlocking, and the session reconnects on its own afterwards. Navigation voice and music play at the same time, the steering wheel changes tracks, and the map is basically smooth once CarWith is set to 60 fps. The full version-by-version history is in the repository README.
  • Wireless ICCOA CarLink reception — Xiaomi CarWith, OPPO Car+, vivo Jovi InCar and similar phones; the phone stays in the pocket or on the wireless charger.
  • Automatic pairing code with a 30-second re-advertise watchdog, so a dismissed prompt on the phone comes back without restarting the app.
  • Full settings tree inherited from the base project — connection, display, video, input, audio, backup, reset and diagnostics.
  • Instrument cluster and HUD projection paths carried over from the base project, for cars that expose those areas. See the honest status below.
  • Car-friendly home screen with large pairing digits, a refresh button and a single entry into settings.
  • Own package and signing key, so MiAuto can be installed next to other receiver apps on the same head unit.
Release notes ↗

Compatibility

Verified on a BYD 宋 Pro DM-i 2022 head unit (DiLink 5.1, Android 10 / API 29, QUALCOMM trinket arm64, 1920×990) with a Xiaomi 15 running HyperOS 4: the app installs, starts by itself after a reboot, advertises, shows a pairing code, completes a CarWith session, and the phone comes back on its own after a disconnect. Not yet verified: the instrument cluster mirror and the windshield HUD navigation, which are carried over from the base project and have not been exercised on hardware. If you run one of those setups, expect to be an early tester and please report what you see.

Updates & signing

MiAuto has its own package name and its own signing key, separate from the projects it was built on. Builds from this repository are signed by that key and will install over each other; they will not install over a build signed by another key, and vice versa.
